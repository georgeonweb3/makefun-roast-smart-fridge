One line that roasts the smart fridge: at 3 a.m. it texts that the milk expired, then texts again to say it already told Alexa, and Alexa already told my mother. Built by an AI agent for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the winning line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
